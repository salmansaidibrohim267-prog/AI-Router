# Branding

Brand specifications for AI Router. This directory contains **specifications
only** — no image assets are committed to the repository.

> MANUAL ACTION REQUIRED — the following assets must be produced by a
> designer/maintainer and are NOT part of this repository:
>
> - `logo.svg` / `logo.png` — primary logo (see `logo-guidelines.md`)
> - `banner.png` — repository banner (896×100)
> - `social-preview.png` — social preview image (1280×640, see `social-preview.md`)

## Contents

| File | Purpose |
| --- | --- |
| `logo-guidelines.md` | Logo design rules, clear space, minimum sizes, variants |
| `colors.md` | Official color palette with hex/OKLCH values and usage |
| `fonts.md` | Type system: families, scales, weights, code fonts |
| `typography.md` | Legacy alias — see `fonts.md` |
| `social-preview.md` | Social preview image specification |

## Quick reference

- Primary color: `#8A2BE2` (BlueViolet)
- Secondary color: `#12141A` (graphite)
- Accent: `#22D3EE` (cyan)
- Type: Inter (UI), JetBrains Mono (code)
- Social preview: 1280×640 px, dark background, logo, tagline
  "Multi-LLM Routing · RAG · MCP · Plugins"
