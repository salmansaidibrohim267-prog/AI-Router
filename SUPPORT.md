# Support

## Community support

- **Issues & bugs** — open a bug report via the
  [issue templates](https://github.com/salmansaidibrohim267-prog/AI-Router/issues/new/choose).
- **Questions** — ask a question using the
  [question template](https://github.com/salmansaidibrohim267-prog/AI-Router/issues/new?template=question.yml).
- **Discussions** — feature ideas and general chat live in
  [GitHub Discussions](https://github.com/salmansaidibrohim267-prog/AI-Router/discussions)
  (enable it in repository settings).

## Before you ask

1. Read the [README](README.md) — it covers installation, configuration,
   API, deployment, security and troubleshooting.
2. Search the [troubleshooting guide](docs/troubleshooting.md) and existing
   issues for your error (e.g. `X-Request-ID`, circuit breaker, provider auth).
3. Include context in your report: version, deployment method, provider,
   and the request ID from the logs.

## Commercial support

For priority support, SLAs, or custom deployments, contact the maintainers
at the address listed in the repository's About section.

## Security issues

Do **not** report vulnerabilities through public channels. See
[SECURITY.md](SECURITY.md).
